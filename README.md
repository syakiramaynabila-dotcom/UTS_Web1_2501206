## Deskripsi Aplikasi
Aplikasi Pemesanan Kantin Kampus adalah aplikasi berbasis web menggunakan PHP native. Aplikasi ini digunakan untuk menampilkan daftar menu makanan dan minuman, mencari menu, menambahkan pesanan ke keranjang, menghitung total pembayaran, dan memberikan diskon.

## Teknologi yang Digunakan
- PHP Native
- HTML
- CSS
- Session
- Cookie
- Git dan GitHub

## Kebutuhan
- XAMPP
- Web browser
- Visual Studio Code
- Git

## Cara Menjalankan Aplikasi
1. Simpan folder project di dalam folder htdocs XAMPP.
2. Jalankan Apache pada XAMPP Control Panel.
3. Buka browser.
4. Masukkan alamat http://localhost/uts-web1-NIM/.

## Fitur Aplikasi
1. Menampilkan daftar menu.
2. Mencari menu berdasarkan nama.
3. Memesan menu menggunakan form.
4. Mengelola keranjang belanja.
5. Menghitung subtotal dan diskon.
6. Menyimpan keranjang menggunakan session.
7. Menyimpan kategori favorit menggunakan cookie.
